Load-bearing quotes:
- 5.3.2 (line 370): "Software must update the backup GPT before the primary GPT, so if the size of device has changed (e.g. volume expansion) and the update is interrupted, the backup GPT is in the proper location on the disk"
- line 370: "Software may update the GPT Header and GPT Partition Entry Array in any order, since all the CRCs are stored in the GPT Header."
- line 371: "If the primary GPT is valid and the backup GPT is invalid software must restore the backup GPT."
- line 368/369: restoring the primary "if allowed by platform policy settings"; "Software must report whenever it restores a GPT."
- 5.3.3 Attributes bits 48-63: "Only the owner of the PartitionTypeGUID is allowed to modify these bits. They must be preserved if Bits 0-47 are modified."
- 5.3.3: "Any time a new partition entry is created a new GUID must be generated"; "If GPT-cognizant software encounters two disks or partitions with identical GUIDs, results will be indeterminate."
- 5.3.1: 512-byte blocks: First Usable LBA >= 34; 4096-byte: >= 6; minimum 16,384 bytes of entry array.
- 5.3.1 alignment: "it may use LBAs that are multiples of 2,048 to align to 1,048,576 byte (1 MiB) boundaries".
