458: Register Level Access: 3.1.14MCHBAR Base Address Register (MCHBAR_0_0_0_PCI) —  Offset 48h This is the base address for the Host Memory Mapped Configuration space. There is no physical memory within this 128KB window that can be addressed. The 128KB reserved by this register does not alias to any PCI 2.3 compliant memory  mapped space. On reset, the Host MMIO Memory Mapped Configuration space is disabled and must be  enabled by writing a 1 to MCHBAREN [Dev 0, offset48h, bit 0]. All the bits in this register are locked in Intel TXT mode. The register space contains memory control, initialization, timing, buffer strength  registers, clocking registers and power and thermal management registers.
