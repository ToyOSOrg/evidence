######## The kill condition (design, PR #873 body), from the scout readbacks ########

Each scout_tlb boot prints, per k in {0,1,4,16,64}:
  "scout_tlb: k=K pages rt_cycles min=.. p50=.. max=.. over 21x500 | parent cpus {..} child cpus {..} ... | parent pmc/rt [4] | child pmc/rt [4]"
and "scout_tlb: tsc N MHz"; each kernel log carries "scout-cpuid: cpuN ... pge=1 cr4=0x..." (head: cr4 with 0x80 set).
It lands only if both hold:
  1. AMD, k=4: HEAD p50 <= 0.98 x BASE p50, and the two min..max ranges are disjoint.
  2. T14, scout_tlb_base, k = 1, 4, 16, 64: no HEAD p50 above BASE's with disjoint ranges.
Killed otherwise. Reported, not gated: AMD full walks per round trip at k=0 (pmc, both arms); T14 itlb walks per round
trip (parent and child); T14 nopcid arm's gain; AMD `tlb: bench` p50/p99 (latencycase), base against head.
