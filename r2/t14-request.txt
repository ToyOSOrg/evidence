Rule, restated before measuring (review round 2). This A/B is evidence, not a landing condition.
- These four boots are a screen. The rows are every wake.*, pingpong.pipe.* and ipc.* row.
- A row whose two head p50s both lie above both base p50s is a candidate. With no
  difference at all, each row is a candidate with chance 1/6, so about 3 of the 18
  rows are expected by chance.
- Candidates get a second B, H, H, B round of these same two images, which the
  implementer requests by name once the screen is read.
- A row is slower only if all 4 head p50s lie above all 4 base p50s: exact two-sided
  p = 2/70, which osbench-compare calls resolved.
- Each row is reported as its head/base median ratio beside both sides' boot-to-boot
  ranges. A row with no flag is reported as "no difference resolved", not as "no cost".
energybenchcase is staged on both sides and is not requested.
