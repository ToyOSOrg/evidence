## Read by hand

Method (WPWS, 0)  { If (GGOV (0x0908000F) == 0) { Local0 = 0 } Else { Local0 = 1 }  Return (Local0) }
Method (WPWC, 1)  { If (Arg0 && (WGFL & 1) && !(WGFL & 8)) { SGOV (0x0908000F, 1); WGFL |= 2 }
                    Else { SGOV (0x0908000F, 0); WGFL &= ~2 } }
Method (BPWS, 0)  { If (GGOV (0x0902000D) == 1) { Local0 = 1 } Else { Local0 = 0 }  Return (Local0) }
Method (BPWC, 1)  { If (Arg0 && (WGFL & 0x10) && !(WGFL & 0x80)) { SGOV (0x0902000D, 1); WGFL |= 0x20 }
                    Else { SGOV (0x0902000D, 0); WGFL &= ~0x20 } }
Method (WGIN, 0)  { WGFL = 0; WGFL = WGSV (1)
                    If (WIN8) { If (WGFL && 0x10) { BPWC (1) } }
                    If (WPWS ()) { WGFL |= 2 }
                    If (BPWS ()) { WGFL |= 0x20 } }

WGSV (1) is SMI_ (9, 1, 0, 0, 0): the SMI handler's answer through SMI_CMD (0xB2, 0xF5).
\_SB.SGOV (0x0902000D, 1) writes GPIOTXSTATE of the pad GADR places at 0xFD6E0A70
(the host trace's "W Memory(fd6e0a70) Byte <- 0x1", and the T14's
"that was Byte 0x1 to Memory(fd6e0a70)").
